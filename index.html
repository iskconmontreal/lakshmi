How to Set Up Your Catalog

  1. Create a Google Sheet with exactly these column headers:
    Name, Category, SuggestedDonation, ImageURL, Description
  2. Add your items as rows (one item per row)
  3. Go to File → Share → Publish to web
  4. Under Link, choose the sheet tab and select Comma-separated values (.csv)
  5. Click Publish and copy the URL
  6. Paste the URL above and click Save URL
  7. Click Refresh Catalog in the header
